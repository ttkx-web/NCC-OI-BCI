## 未确认问题

- 设备是否提供可验证的单位、增益和缩放证据？
- 时间戳是否逐样本提供，还是仅提供 chunk 到达时间？
- Marker 能否与 EEG 共享同一时间基准？
- 重连后是否可能重复、乱序或重置 sequence ID？
