| ---------------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------- |
| 通道数量             | 22                          | 64 个固定位置                                                                   | 读取当前窗口的通道名，映射到固定 64 通道；多余通道忽略，缺失位置补 0                         |
| 通道名称             | ['Fz', 'FC3', 'FC1', 'FCz', 'FC2', 'FC4', 'C5', 'C3', 'C1', 'Cz', 'C2', 'C4', 'C6', 'CP3', 'CP1', 'CPz', 'CP2', 'CP4', 'P1', 'Pz', 'P2', 'POz']                              | 常见 10-20 系统固定模板                                                            | 使用 50M 的通道名规范化函数，处理大小写、前后缀以及 T3/T4/T5/T6 别名                   |

| 原始采样率            | 250Hz                                                      | 不限定原始采样率                                                                   | 从 HDF5 metadata 获取原始采样率                                       |
| 模型目标采样率          | **200 Hz**                                                                                     | **100 Hz**                                                                 | 将 50M 分支的目标采样率改为 100 Hz；不要先转成 200 Hz 后再二次重采样                  |

| 窗口时长             | **4 秒**                                                                                        | 默认 **10 秒**                                                                | 第一版可保留 4 秒，但需要重新生成 4 秒 Token，并重新训练分类头                         |
| 输入点数             | 预处理后：`4 秒 × 200 Hz = 800 points/sample`；每个 Patch 200 点，共 4 个 Patch                             | 默认：`10 秒 × 100 Hz = 1000 points/sample`；每个 Token 100 点                     | 采用 4 秒方案时应为 `400 points/sample，100 points/token`              |
| 输入预处理前形状         | 单窗口 `[C,T]`；批数据 `[N,C,T]`                                                                      | 原始输入 `[C_in,T]`                                                            | 50M Adapter 接收 Pipeline 的 `[C,T]` 及 channel names、sample rate |
| 当前模型实际输入形状       | 单窗口 **`[C,4,200]`**；批输入 **`[B,C,4,200]`**                                                      | 默认 `token_inputs: [B,640,100]`；4 秒时为 `[B,256,100]`                         | 不要直接把 `[B,C,4,200]` 送入 50M；需要重新走 50M 的 100 Hz Patch/Token 构造  |
| 数据类型             | HDF5 EEG 为 `float32`；预处理计算中暂转 `float64`，最后返回 `float32`；送入模型时转为 Torch 浮点张量                      | EEG Token `float32`；通道/时间索引 `int64/torch.long`；Mask `float32`              | Adapter 内显式转换各输入 dtype                                        |
| 标准化              | **每个窗口、每个通道沿时间维做 Z-score**                                                                     | 有效通道按通道沿时间做 Z-score，缺失通道维持 0                                               | 两边标准化思路基本相同，但需统一 epsilon 和先后顺序                                |
| 滤波               | 0.1–75 Hz bandpass + 50 Hz notch                                                               | 50M 已检查的数据构建代码中没有明确执行相同的 bandpass/notch                                    | 不要默认复用当前滤波；需向 50M 模型负责人确认实际 checkpoint 的训练预处理                 |
| 参考方式             | 当前 Pipeline 预处理代码中**没有重新平均参考**                                                                 | 50M 仓库的两个预处理路径不一致：`preprocessing.py` 有平均参考，但实际大规模构建脚本未显示该步骤                | 必须确认实际 50M checkpoint 用的是哪条数据处理路径，暂时不能武断填写                    |
| 缺失通道             | **没有补 0、没有 valid mask、没有插值**；只保留当前存在的 EEG 通道                                                   | 缺失位置补 0，并生成 `channel_valid_mask` 和 `token_valid_mask`                      | 新增固定 64 通道映射、补 0 和 Mask 构造                                    |
| 当前输出层            | LaBraM 最后一层 Transformer 后的 Patch Token，经 final norm 后做 **mean pooling**                        | `extract_token_embeddings()` 指定 Transformer 层；默认微调设置为 `return_layer_idx=8` | 为 50M 固定输出层，并将层号写入模型包配置                                       |
| 当前 Backbone 输出维度 | **`[B,200]`**                                                                                  | 默认 10 秒为 `[B,640,512]`；4 秒为 `[B,256,512]`                                  | 需要决定 Flatten 或 Pooling，并重新定义分类头                               |
| 当前分类头输入维度        | 200                                                                                            | 默认 Flatten：10 秒为 327680；4 秒为 131072                                        | 使用 4 秒输入时重新训练 131072 输入维度的分类头，或重新实验 pooling                   |
| 最终预测输出           | 线性头输出 `[B,4]` logits，再 Softmax 得到 `[B,4]` probabilities；返回 prediction、confidence、probabilities | `[B,num_classes]` logits 和概率                                               | 封装成当前 `predict_proba()` 的统一接口即可                               |
